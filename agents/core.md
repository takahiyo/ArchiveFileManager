# コアエージェント指示書

## 役割

機能実装を担当し、ユーザーの要望する仕様の実現・軽量化・拡張性の確保を行う。

## 担当ファイル

| ファイル | 内容 |
|----------|------|
| `src/archive_handler.py` | アーカイブ操作（展開・圧縮・変換・一括変換） |
| `src/extension_fixer.py` | 拡張子検証・修正（マジックバイト判定） |
| `src/folder_normalizer.py` | フォルダ階層正規化 |
| `src/config.py` | 定数・設定の一元管理（SSOT） |
| `src/main.py` | エントリポイント |

## 責務

### 1. 仕様実現

- ユーザーの要望を正確に機能として実装する
- アーカイブ形式の変換処理（ZIP ↔ RAR ↔ 7z）
- 拡張子の自動修正（マジックバイト照合）
- フォルダ階層の正規化（不要な入れ子の除去）
- バッチ処理（複数ファイルの一括変換）

### 2. 軽量化

- 不要な一時ファイルの確実な削除
- メモリ効率を意識した処理（大量ファイル対応）
- サブプロセス呼び出しの最適化
- ループ・リスト操作の効率的な記述

### 3. 拡張性の確保

- 新しいアーカイブ形式の追加が容易な設計を維持する
- `config.py` の定数テーブル方式を活用する
- 関数の引数はコールバック・オプション辞書で柔軟に
- 依存注入パターンを維持し、テスト可能な設計を保つ

### 4. SSOT の実践

- 新しい定数は必ず `config.py` に追加
- 既存の定数テーブルのパターンに従う
- マジックナンバーの禁止（意味のある名前を付ける）

## 設計原則

### 関数設計

```python
def convert_archive(
    input_path: str,
    output_dir: str,
    target_format: str,
    compression_level: int = 3,
    *,
    log_callback: callable | None = None,
    cancel_event: threading.Event | None = None,
) -> str | None:
    """アーカイブを指定形式に変換する。

    Args:
        input_path: 入力ファイルパス
        output_dir: 出力先ディレクトリ
        target_format: 変換先形式（"ZIP", "RAR", "7z"）
        compression_level: 圧縮率（0-5、デフォルト: 3=標準）
        log_callback: ログ出力用コールバック（任意）
        cancel_event: キャンセル制御用イベント（任意）

    Returns:
        変換後のファイルパス。失敗時はNone。
    """
```

### エラーハンドリング

```python
# サブプロセスの失敗は戻り値で通知（例外を乱用しない）
# ログコールバックでユーザーに状況を伝える
if result.returncode != 0:
    if log_callback:
        log_callback(f"変換失敗: {input_path} ({result.stderr})")
    return None
```

### 定数追加パターン

```python
# config.py に追加する際は既存のパターンに合わせる
# --- セクションコメント ---
NEW_CONSTANT = "value"  # 用途の説明コメント
```

## コア変更時のチェックリスト

- [ ] 新規定数を `config.py` に追加したか（ハードコーディング禁止）
- [ ] docstring を記述したか（目的・引数・戻り値）
- [ ] 型ヒントを付与したか
- [ ] 一時ファイル・ディレクトリの後処理（削除）を実装したか
- [ ] サブプロセスのエラーハンドリングを実装したか
- [ ] キャンセル対応（cancel_event チェック）を実装したか
- [ ] 既存の関数シグネチャを変更していないか（変更した場合は呼び出し元を全て更新）
- [ ] GUI層に影響する変更は GUI エージェントに連絡したか

## 禁止事項

- GUI関連のコード（tkinter import 等）をコア層に記述すること
- `config.py` を経由せず定数を直接記述すること
- 呼び出し元を確認せず関数シグネチャを変更すること
- 一時ファイルを後処理せず放置すること
- 外部コマンド（WinRAR等）のパスをハードコーディングすること
