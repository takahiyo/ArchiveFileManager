# GUI エージェント指示書

## 役割

GUIデザイン・操作性・視認性にこだわり、ユーザーが快適に使えるインターフェースを実現する。

## 担当ファイル

| ファイル | 内容 |
|----------|------|
| `src/gui.py` | メインGUI（ArchiveFileManagerGUI クラス） |
| `src/config.py` | GUI関連の定数（統括・コアと連携） |

## 責務

### 1. UIデザイン

- Tkinter ウィジェットの配置・スタイリング
- 色・フォント・余白の統一感
- ウィンドウサイズ・リサイズ時の挙動

### 2. 操作性（UX）

- ユーザーの操作フローが自然であること
- ボタン・ラジオボタン・チェックボックスの配置が直感的であること
- キーボード操作への対応
- 処理中のUI状態管理（ボタン無効化、キャンセル導線）

### 3. 視認性

- ログ表示の見やすさ（フォント、色分け、自動スクロール）
- プログレスバーの正確な進捗表示
- ステータス表示の分かりやすさ
- エラー・警告の目立つ表示

### 4. コア機能との連携

- コアエージェントが提供する関数をコールバック経由で呼び出す
- GUIからコアへ渡すオプション辞書の設計
- スレッド処理による非同期実行（UI フリーズ防止）

## 設計原則

### レイアウトルール

```python
# --- ウィジェット配置はグリッド or パックで統一 ---
# 同一画面内でgridとpackを混在させない
# セクションごとにLabelFrameで区切る
```

### コールバックパターン

```python
# GUIからコア機能を呼ぶ際は、必ずコールバック辞書を経由する
options = {
    "target_format": self.selected_format.get(),
    "compression_level": COMPRESSION_LEVELS[self.selected_level.get()],
    "delete_original": self.delete_var.get(),
    "recursive": self.recursive_var.get(),
}

# ログ出力・進捗更新もコールバックで
callbacks = {
    "on_log": self.append_log,
    "on_progress": self.update_progress,
}
```

### スレッド安全性

```python
# コア処理はバックグラウンドスレッドで実行
# UI更新は必ず root.after() 経由で行う
self.root.after(0, self.append_log, message)
```

## GUI変更時のチェックリスト

- [ ] レイアウト崩れがないか（ウィンドウリサイズ時も含む）
- [ ] ボタンの有効/無効状態が正しいか
- [ ] 処理中にUIがフリーズしないか
- [ ] ログ表示が正しく更新されるか
- [ ] プログレスバーが0%→100%まで正しく動作するか
- [ ] キャンセル操作が正しく機能するか
- [ ] エラー時にユーザーに分かりやすいメッセージが表示されるか
- [ ] config.py の定数を参照しているか（ハードコーディング禁止）

## 禁止事項

- ビジネスロジックをGUI層に記述すること（コア層に委譲する）
- UIスレッドで重い処理を直接実行すること
- ウィジェットのスタイル値（色・フォント等）を直接ハードコーディングすること
- コア層の内部実装に依存するコード（公開APIのみ使用）
